ScriptToon samples

Short hand-drawn cartoons rendered from a Markdown storyboard. Each one below was made from someone's README or launch post on DEV, unasked, and left in their comments as a gift. Fifteen so far; six of the authors have replied in the threads, none asked for a change. The engine and the cut-out character module are a package: ScriptToon on Payhip. If you'd rather have one made for your project, that's a separate listing: done-for-you explainer.
